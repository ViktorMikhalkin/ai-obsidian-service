# Security Policy

## Supported Versions
We currently support security updates only for the latest release.

## Reporting a Vulnerability
If you discover a security vulnerability in this project, please report it responsibly.

- **Do not** open a public GitHub issue.
- Instead, send an email to the maintainers (see repository profile) or use GitHub Security Advisories if available.
- Provide as much detail as possible: environment, steps to reproduce, potential impact.

We will investigate promptly and work with you to coordinate disclosure.
